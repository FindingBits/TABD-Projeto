About the Project

This platform was developed as part of the practical assignment for the Advanced Topics in Databases (TABD) course unit.

System Objective

The system aims to cross-reference the Local Election results in Portugal with the Official Administrative Map of Portugal (CAOP 2025). The primary objective is to convert raw tabular and statistical data from the National Elections Commission (CNE) into interactive visual and geographical knowledge.

Architecture and Data Engineering

Strictly following the project's methodological requirements, the application adopts a layered architecture:

  • Staging Area: An intermediate persistence layer where spatial data from the CAOP GeoPackages (Mainland, Azores, and Madeira) are injected in a clean and isolated manner.
  • ETL Processing: Python pipelines (utilising GeoPandas and SQLAlchemy) that handle format normalisation, schema matching, and uniform cartographic projection to the official national system (EPSG:3763).
  • Database Engine: PostgreSQL with the PostGIS spatial extension enabled, responsible for processing complex geographical queries and exposing optimised polygons via GeoJSON.
  • Thin Web Layer: A responsive frontend built with HTML5 and Bootstrap, utilising the Leaflet library to render dynamic maps with segmented regional navigation (drill-down).
